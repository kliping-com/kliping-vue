## Instalasi

<Steps>

### Perbarui `css`

Tambahkan style tooltip berikut ke berkas `tailwind.css` Anda:

```css
@layer base {
  :root {
    /* ... */
    --vis-tooltip-background-color: none !important;
    --vis-tooltip-border-color: none !important;
    --vis-tooltip-text-color: none !important;
    --vis-tooltip-shadow-color: none !important;
    --vis-tooltip-backdrop-filter: none !important;
    --vis-tooltip-padding: none !important;

    --vis-primary-color: var(--primary);
    /* change to any hsl value you want */
    --vis-secondary-color: 160 81% 40%;
    --vis-text-color: var(--muted-foreground);
  }
}
```

Kalau komponen Anda tidak memakai `css-variables`, isi `--vis-primary-color` dan `--vis-text-color` dengan nilai hsl yang Anda inginkan.

[Alat ini](https://redpixelthemes.com/blog/tailwindcss-colors-different-formats/) bisa membantu Anda menemukan nilai hsl untuk warna primary dan warna teks Anda. Jangan lupa sediakan style untuk mode `dark` juga.

</Steps>

## Warna

Secara bawaan, warna primary tema dan warna secondary (`--vis-secondary-color`) disusun dengan tingkat opasitas berbeda untuk grafiknya.

Meski begitu, Anda selalu bisa meneruskan `color` sendiri ke tiap grafik.

```vue
<template>
  <AreaChart
    :data="data"
    :colors="['blue', 'pink', 'orange', 'red']"
  />
</template>
```

## Tooltip Kustom

Kalau Anda ingin menyesuaikan `Tooltip` grafiknya, teruskan prop `customTooltip` berisi komponen Vue buatan Anda sendiri.
Komponen tersebut menerima prop `title` dan `data`. Lihat [komponen ChartTooltip.vue](https://github.com/unovue/shadcn-vue/tree/dev/apps/www/registry/default/ui/chart/ChartTooltip.vue) sebagai contoh.

Definisi prop yang diharapkan:

```ts
defineProps<{
  title?: string
  data: {
    name: string
    color: string
    value: any
  }[]
}>()
```

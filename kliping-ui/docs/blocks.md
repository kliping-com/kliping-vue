# Blocks

34 halaman siap pakai yang disusun dari komponen di pustaka ini. Semuanya
berupa berkas Vue biasa di `src/blocks/` — salin foldernya ke project Anda, lalu
ganti isinya.

Tiap kartu di bawah adalah halaman block yang sungguh-sungguh berjalan, dibingkai
pada lebar desktop lalu diperkecil. Klik untuk membukanya utuh.

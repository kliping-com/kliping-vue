---
title: Instalasi Manual
description: Menambahkan dependensi ke project Anda secara manual.
---

Cara ini cocok kalau Anda ingin memahami setiap potongan yang dipasang, atau kalau struktur
project Anda tidak cocok dengan asumsi CLI.

<Steps>

### Pasang Tailwind CSS

Semua komponen di-style memakai Tailwind CSS, jadi Tailwind harus terpasang lebih dulu di project Anda.

[Ikuti panduan instalasi Tailwind CSS untuk memulai.](https://tailwindcss.com/docs/installation)

### Pasang dependensi

Tambahkan dependensi berikut ke project Anda:

```bash
npm install class-variance-authority clsx tailwind-merge @lucide/vue tw-animate-css
```

### Atur alias path

Daftarkan alias path di file `tsconfig.json` Anda.

```json showLineNumbers {3-6} title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

Alias `@` hanya kebiasaan, bukan keharusan. Anda bebas memakai alias lain.

### Atur style

Tambahkan isi berikut ke file `styles/globals.css` Anda. Penjelasan lebih jauh soal CSS
variable untuk theming ada di [halaman Tema & Kustomisasi](/theming).

### Tambahkan helper `cn`

```ts showLineNumbers title="lib/utils.ts"
import type { ClassValue } from 'clsx'
import { clsx } from 'clsx'
import { twMerge } from 'tailwind-merge'

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

### Buat file `components.json`

Buat file `components.json` di root project Anda. File ini hanya diperlukan kalau Anda
berencana memakai CLI nantinya.

```json showLineNumbers title="components.json"
{
  "$schema": "https://kliping.pro/schema.json",
  "style": "new-york",
  "typescript": true,
  "tailwind": {
    "config": "",
    "css": "src/styles/globals.css",
    "baseColor": "neutral",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "composables": "@/composables",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib"
  },
  "iconLibrary": "lucide",
  "pointer": false,
  "rtl": false
}
```

### Selesai

Sekarang Anda bisa mulai menambahkan komponen ke project — baik dengan gunting-tempel manual
dari [halaman komponen](/components), maupun lewat CLI.
